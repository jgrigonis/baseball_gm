Mumbai Mariners

A harbor town's team. Saffron like marigold garlands, deep teal like the Arabian Sea off Marine Drive, and cream like the stone of the Gateway of India. The lettering has the hand-painted feel of a Mumbai shop sign, with waves running under it and an anchor on the cap.

Design notes

  • Built from the team's three colors. Saffron, teal and cream are the same values the game uses for the Mumbai badge. The only addition is a green-leaning gray for the away pants.
  • Sign-painter lettering. Yatra One is drawn in the style of Indian hand-painted signs and covers both English and Devanagari, so the patch's मुंबई matches the jersey's Mariners.
  • The wave sits under the script. Vienna's stroke through the script didn't work, so this one runs fully beneath the word.
  • A gentle 10° climb. Steeper than flat for some motion, but less than Vienna's 26° so the two teams don't look alike.
  • Saffron gets an edge on cream. It's bright but light, so it carries a teal or cream outline where it meets cream.
  • In the game. These are design drawings only for now. Nothing in the app has changed.


Make src/db/connection.py like this

def get_connection(db: str | Path = "league.db") -> sqlite3.Connection:
    path = Path(db) if Path(db).is_absolute() else Path(LEAGUE_FILES_DIR) / db
    conn = sqlite3.connect(path)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    return conn

Everywhere you find something like:


conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    cur = conn.cursor()

replace with:

from src.db.connection import get_connection
conn = get_connection()
cur = conn.cursor()


This is a tedious refactor, but the key is enforcing the 

conn.execute("PRAGMA foreign_keys = ON")

After every call of sqlite3.connect

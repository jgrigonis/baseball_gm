1. Pitcher Win (W)

A pitcher gets the win if:
Their team takes the lead while they are the pitcher of record, and
That lead is never relinquished

Starting Pitcher special rule
Must pitch at least 5 innings (MLB rule)
If not, the win goes to the relief pitcher deemed most effective (usually first reliever who holds the lead)

Practical sim-friendly rule
For a simulator (especially early versions):

Track lead changes

When the batting team scores:
Record the current opposing pitcher

The pitcher on the mound when the winning run is scored becomes the win candidate

At game end:
If that pitcher is a starter with < 5 IP → assign win to best reliever after him (or first reliever)

2. Pitcher Loss (L)

A pitcher gets the loss if:
He is the pitcher responsible for the run that puts the opposing team ahead
That lead is never relinquished

Implementation rule
On every scoring play:

If the score breaks a tie or flips the lead
Assign loss responsibility to the current pitcher

At game end:
That pitcher gets the loss

This one is simpler than wins.

3. Save (S)

A pitcher earns a save if all are true:
He is not the winning pitcher
He finishes the game
He pitches in a save situation, defined as:
Enters with a lead of 3 runs or fewer, OR
Enters with the tying run on base, at bat, or on deck, OR
Pitches 3+ innings to finish the game

Common simplified sim rule
Most sims use:
Relief pitcher enters in the 9th (or later) with a lead ≤ 3 and finishes → Save

That’s totally acceptable unless you want deep realism.

4. What You Should Track During the Game

Add these to your Game object:

self.pitchers_of_record = []
self.current_pitcher = None
self.lead_changes = []


When runs score:

def record_run(self, scoring_team):
    if scoring_team takes the lead:
        self.lead_changes.append({
            "pitcher": self.current_pitcher,
            "inning": self.inning.number,
        })

5. Assigning Results at Game End
Win
winning_event = self.lead_changes[-1]
win_pitcher = winning_event["pitcher"]


Check starter innings rule → adjust if needed.

Loss
loss_pitcher = winning_event["pitcher"] on losing team

Save
closer = pitcher who finished the game

if closer != win_pitcher and save_conditions_met:
    closer.stats.pitching.save += 1

6. Where This Logic Belongs

Not in PitchingStats.

It belongs in:

Game

or GameResultResolver

or ScoringEngine

Stats should be dumb counters, not rule engines.

7. Pro Tip (Design Insight)

MLB official scorer rules are messy and subjective.

For a simulator:

Be consistent

Be explainable

Be deterministic

You can always add:

ruleset="mlb_strict" | "sim_simple"


later.

TL;DR Implementation Strategy

Track who is pitching

Record who was pitching when the winning run scored

Assign:

Win → pitcher of record for winning run

Loss → pitcher who gave up that run

Save → last pitcher if save conditions apply

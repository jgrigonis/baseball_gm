Draft page needs a redesign

We should have 3 columns, each independently scrollable.
The left most column is your "draft preferences" or "draft priority"
This column isn't sortable it's only manipulated through drag and drop
OR, via arrows on the player rectangles, to shift a player up or down
It begins simply sorted by Overall rating (the one the user can see, not the 
numeric value) It should have a secondary sort which is the higher of Contact
or Stuff, and a tertiary sort which is the higher of Power or Control.
That sorting doesn't have to be obvious to the human player. Atop the prefences column
is a reset to default button that will return the preferences to the initial state

The middle column is where all the user initiated sorting takes place.
It starts in the same initial state as the column on the left. It however is controlled via 
sorting and filtering controls. It will have "Sort" set to "Overall" "then" set to "-" and then another "finally" set to "-"
but the initial state will be the same as left column, which technically follows that sort but secretly applies 
the 2 other sorts.

We do that because so many of the top draft picks are all ending up with the same ratings. 31/650 were rated B+
in my last draft, 209/650 were rated B.

The ratings not giving a good spread itself is a small problem we need to fix elsewhere.

Also on that middle column you can flip each ranking to reverse. Also you can filter out hitters and pitchers
The idea is to sort how you want, then drag a plyer from the center column to the left.

Overall, STF, CTL, STA, REC, GB, Contact, POW, EYE, SPD, Fielding

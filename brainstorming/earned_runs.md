The right way to track earned runs (step by step)

1. Reconstruct the inning without errors

This is the golden rule.
When an error happens, you mentally (or on the scorecard) erase that error and ask:
Would this run have scored if the defense had played perfectly?

If the answer is yes, the run is earned.
If no, it’s unearned.

2. Watch for these common situations

Runs are unearned if they score because of:
A fielding error (misplay, bad throw, dropped ball)
A passed ball (but not a wild pitch)
An inning that should have ended if not for an error

Runs can still be earned if:
The pitcher gives up hits, walks, or hit batters (even after an error), as long as the inning would still be alive
A wild pitch allows a runner to advance
A reliever inherits runners (those runs belong to the previous pitcher)

3. Handle multiple errors carefully

If there are two or more errors in an inning, you still:
Remove all errors
Rebuild the inning from scratch
Only count runs that would score in that clean version
This is where earned-run decisions get tricky—and where official scorers earn their paycheck.

4. Assign runs to the correct pitcher

Starter or reliever who allowed the runner on base gets charged with the run
Even if another pitcher gives up the hit that scores them

Example:

Pitcher A walks a batter, then gets pulled.
Pitcher B gives up a double, the runner scores.
👉 Run is charged to Pitcher A

A quick rule of thumb

If you’re ever unsure:

No error = earned.
Error keeps inning alive = unearned.

Why it matters

Earned runs directly affect:

ERA (Earned Run Average)
Pitcher evaluations
Contract incentives

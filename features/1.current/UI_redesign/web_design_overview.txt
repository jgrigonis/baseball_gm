More explanatory of the vision

"how it starts", what's the first thing they see.



First, the user probably has to decide if they are a guest, or if they want to "sign in". I am imagining we 
could support guest users from the same browser/computer even for a long time, but if they want to move to 
a different machine they'd need some kind of login.

I am fine with using Google authentication for that. Login with your gmail account.



The first step is joining a league. Ideally, there would be some kind of tutorial league explaining all the 
things you are expected to do to "play" the game. This is still not done.



Once they are ready to join a "real" league, they can start with a single player blitz league.



Alternatively, jump right into a multiplayer league.



And of course, the non-blitz style leagues, either solo or in a multiplayer environment.
These long form games don't exist yet, but we have most of the building blocks.
I still want to focus on fine tuning the blitz experience.


Once you are "playing" the game you will have something like a dashboard. Basically, it is a series
of tabs over the main view, whichever tab you are in is highlighted.



As the game progresses from states:



lobby -> draft (preseason) -> regular season -> playoffs -> go back to draft state.



The dashboard would vary slightly based on the game state.
Before the draft, there is no draft results tab, you are taken there, after the draft and it appears. This
is already handled correctly.
Leders and Stats tabs can be hidden during draft and preseason, since there is no data. It might make sense to add
them if we could look at historical seasons. But for sure we can hide them for now, and during the first season.
The playoffs tab shows up once the season is complete, this is already handle correctly.



So in the lobby, you'd see the other players in the league, you'd see the join code to invite people, you'd see the 
settings for the league (these aren't really variable yet), but things like number of teams, season length, number 
of seasons, granularity of control, etc. These options will be scoped out elsewhere.
See: lobby_enhancements



See: Draft_page_redesign



Once the draft runs, you'd begin immediately the regular season. As this is where most of the game is "played" you'd 
have access to the most things here, probably many too big to fit into a single dashboard view, so tabs.



In the playoff screen, it's quite similar to the regular season, but you are much more likely to need to make adjustments 
now, with almost certainly some injuries, and fatigue coming into play, optimizing star pitchers, etc



The evaluation stage is basically just a summary of the season. This code doesn't exist yet, but basically, grading the 
GMs, potentially even firing them



Then it begins another year with the draft



There are more stages to include someday in the future and certain deadlines, but not for v1

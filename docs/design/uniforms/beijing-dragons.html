Design notes

  • Built from the team's three colors. Red, blue and gold are the same values the game uses for the Beijing badge, which already shows 北京. I added a cream for the home body.
  • Two scripts. Heavy block capitals for DRAGONS, and brush calligraphy (Ma Shan Zheng) for 北京 on the road jersey and the patch.
  • One symbol on the cap. The dragon, following the anchor, spire, falcon, morion, tower, wing, tulip, eagle, shamrock and star.
  • In the game. These are design drawings only for now. Nothing in the app has changed.

postgresql install notes:

Installed from EDB Installer on MacOS.

Added this to the .zshrc file:

export PATH="/Library/PostgreSQL/18/bin:$PATH"

Then I was able to run the following commands:

psql -U postgres

\l 
to list all databases

create database baseball_manager;

It is setup to run at boot time.


On Macbook I instead:

brew install postgresql 

Brew says:
To start postgresql@18 now and restart at login:
  brew services start postgresql@18
Or, if you don't want/need a background service you can just run:
  LC_ALL="en_US.UTF-8" /opt/homebrew/opt/postgresql@18/bin/postgres -D /opt/homebrew/var/postgresql@18

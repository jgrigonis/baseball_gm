Frankfurt Eagles

Neues Frankfurt: the 1920s modernist housing program that set the city's signs in Futura. This set uses black, red and gold with a clean white home. The lettering is a geometric sans in the Futura mold, set straight across with a tricolor bar beneath it. The cap carries a geometric eagle, and the patch is a Bauhaus-style square with the eagle on a red disc.

Design notes

  • Built from the team's three colors. Black, red and gold are the same values the game uses for the Frankfurt badge, and the order of the German flag. I added a white for the home body.
  • Straight, not arched. Every team so far has arched or angled lettering. Frankfurt sets it level with a tricolor bar underneath, for a cleaner modernist look.
  • Geometric sans. Jost follows Futura, the typeface the Neues Frankfurt program used on its signs.
  • One symbol on the cap. The eagle, following the anchor, spire, falcon, morion, tower, wing and tulip. It is drawn from straight cuts, not taken from any coat of arms.
  • In the game. These are design drawings only for now. Nothing in the app has changed.
